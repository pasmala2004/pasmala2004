## 🚀 Currently Building

### Etbaly — AI-Powered 3D Printing App
A full-stack 3D printing application that converts images and text into
printable 3D models using state-of-the-art AI.

**My Role:** AI/ML Engineer

**What I built:**
- 🤖 Integrated **Hunyuan3D-2mini** (Tencent) for image → 3D shape generation
- 🎨 Integrated **HunyuanDiT** for text → image generation
- 🔧 Built a **Flask REST API** serving the AI models on GPU
- 🖨️ Built a **3D printing slicer** with 3 profiles (Demo, Normal, Heavy)
- ✅ Built an **STL printability checker** (watertight, normals, wall thickness)
- ⚡ Deployed on **Lightning.ai** with free T4 GPU

**Tech Stack:**
`Python` `Flask` `PyTorch` `Hunyuan3D` `trimesh` `Lightning.ai`
